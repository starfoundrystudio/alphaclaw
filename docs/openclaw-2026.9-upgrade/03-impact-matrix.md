# AlphaClaw impact matrix for OpenClaw 2026.9.4 (Phase 3)

Status: **draft for Bill's review (Checkpoint 1).** Built from
[`01-change-inventory.md`](01-change-inventory.md),
[`02-code-deep-dives.md`](02-code-deep-dives.md), and a full inventory of every
AlphaClaw code path that reads, writes, spawns, or parses OpenClaw-owned state
(scratch inventory `alphaclaw-openclaw-touchpoints.md`, 14 sections). Every
row below was verified against the `v2026.9.4` tree, not inferred from release
notes.

Severity legend:

- **S0 — blocks boot or upgrade.** Instance will not start, or the upgrade
  cannot be applied safely, until fixed.
- **S1 — breaks a user-facing feature or corrupts state.** Must ship in the
  same release as the pin bump.
- **S2 — degraded behaviour or drift.** Should ship with the bump; can be
  staged if isolated.
- **S3 — hygiene / tests / docs.**
- **Decide** — architectural choice for Bill before Phase 6.
